# Support

Use [GitHub Issues](https://github.com/sbarisic/CTilde/issues) for reproducible compiler, language-server, project-system, installation, and command failures.

Include the Visual Studio version, extension version, target and compiler from `ctilde.json`, the **C~** output pane, debugger trace when relevant, GDB version, and exact reproduction steps. Do not include credentials or proprietary source files.

For Marketplace identity or listing problems, use the support link on [ctilde.sbarisic.com](https://ctilde.sbarisic.com).
