# Original language idea

Add a variable form that permits one runtime assignment. This form must differ from `const` because initialization can occur after declaration.

Draft 0.2 specifies this behavior through `readonly` fields and local variables. The compiler does not implement it.

See [../LANGUAGE.md](../LANGUAGE.md) for the design. See [../IMPLEMENTATION_STATUS.md](../IMPLEMENTATION_STATUS.md) for the implementation roadmap.
